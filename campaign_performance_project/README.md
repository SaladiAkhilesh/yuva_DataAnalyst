# Data Analysis and Visualization for Campaign Performance

## Objective
Analyze simulated digital marketing campaign data and visualize key performance metrics.

## Dataset
`campaign_data.csv` contains 120 campaign-day observations for four campaigns and four platforms over 30 days. It is **simulated sample data** created for the internship exercise.

## Metrics
Impressions, Clicks, Conversions, Engagements, Spend, CTR, Conversion Rate, Engagement Rate, CPC and CPA.

## Tools
Python, Pandas, NumPy and Matplotlib.

## Visualizations
1. Impressions by campaign
2. Daily click trend
3. Conversions by campaign
4. CTR by platform
5. Engagement rate by platform
6. Daily conversion rate
7. Correlation matrix

## Run
```bash
pip install pandas numpy matplotlib
python campaign_analysis.py
```
